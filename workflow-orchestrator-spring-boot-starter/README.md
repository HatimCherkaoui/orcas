# Workflow Orchestrator Spring Boot Starter

The standard all-in-one Spring Boot entry point for ORCAS.

Add this single dependency when the application wants the complete ORCAS runtime stack. It brings the core Spring wiring plus JDBC persistence, Kafka events/listeners, REST workflow steps, Resilience4j integration, OpenTelemetry observability, the operational workflow REST service, and the Kafka dashboard service.

Feature starters remain available independently, so applications can opt out of capabilities they do not need.
